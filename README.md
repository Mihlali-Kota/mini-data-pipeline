# mini-data-pipeline

> **Status: just started.** This README is a placeholder. There is no working pipeline yet.

## What this project is

This is my learning project for data engineering, built from first principles. The goal is to build a retail data pipeline step by step: take raw transaction data, check its quality, clean it, and turn it into numbers a business can trust.

## How I'm learning

I'm being taught by Claude (an AI) acting as my tutor. The tutor's job is not to write the code for me. It explains the concepts, points me to documentation, asks questions, and reviews what I write. I do the thinking, research, coding, testing, and debugging myself, and I have to be able to explain and defend my decisions.

## Plan

The project will grow in stages: reading and profiling the data, validating and cleaning it, adding tests, loading it into a database, and making it reliable to rerun. Only things I have actually built and tested will be claimed here.

## Data

The dataset is not chosen or verified yet. I'll check its licence and format before using it, and large data files will not be committed to this repository.
